🤖 AI 功能設定

☁️ Google Sheets 雲端同步

📌 第一次設定步驟：
1. 開啟 script.google.com → 新增專案
2. 貼入專案的 Code.gs 程式碼（覆蓋原內容，並把 SHEET_ID 換成你的試算表 ID）→ 儲存
3. 點「部署」→「新增部署作業」→ 類型選「網路應用程式」
4. 執行者：我、存取權：任何人 → 部署 → 複製網址貼到上方
5. ⚠️ 每次修改 Script 都需要「管理部署作業 → 編輯 → 新版本」重新部署才會生效
6. 🔑 在 Apps Script 編輯器選函式「setupApiKey」執行，複製執行記錄裡的密鑰，貼到上方「同步密鑰」並儲存 
此處原本的範例程式碼已過時（單一儲存格存全部資料，容易超過上限，且沒有備份與衝突保護）。
請改用專案中的 Code.gs：整份貼入 Apps Script 覆蓋原內容，並重新部署（新版本）。
首次使用請記得把檔案開頭的 SHEET_ID 換成你自己的試算表 ID。

💾 本機備份

把全部資料存成檔案，放在手機或電腦裡。iOS Safari 約 7 天沒開啟，網站資料可能被清除；建議定期匯出，並把 App 加到主畫面。

🧾 匯入信用卡帳單

選擇銀行寄來的帳單 PDF（永豐、台新、星展、中信；可一次選多個），在手機上解析，不會上傳。解析後可逐筆修改、刪除、新增，再匯入記帳。
🔑 PDF 密碼
存好之後，上傳有密碼的帳單會自動依序嘗試，不用每次輸入。只存在這台裝置：不會同步到雲端，也不會進備份檔。
🚫 匯入排除名單
商家名稱含這些關鍵字的列（例如統一報公帳的），預覽時會預設取消勾選，並收在最下面的「已排除」區，需要時還是可以手動勾回來。全形半形、大小寫視為相同。
